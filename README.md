## 👩‍💻 Sobre mí

Soy desarrolladora web y **IT Manager** con experiencia real en entornos profesionales, combinando la gestión técnica de infraestructuras con el desarrollo de aplicaciones web robustas y orientadas al usuario.

Me especializo en el ecosistema **Laravel / PHP / JavaScript** y tengo especial interés en construir productos que aporten valor real a las personas — desde plataformas corporativas hasta aplicaciones con impacto social.

Actualmente cursando el **Grado en Ingeniería Informática** en la **UOC**, y siempre abierta a nuevos retos técnicos.
